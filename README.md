# درعك — فاحص الرسائل والروابط

نسخة أولية ثنائية اللغة (العربية والإنجليزية) تعمل في المتصفح. الصق رسالة أو رابطًا، وستظهر لك مؤشرات الاشتباه وأسبابها.

## التشغيل

افتح `index.html` في متصفح حديث. لا يحتاج المشروع إلى تثبيت برامج أو إنشاء حساب. استخدم زر اللغة أعلى الصفحة للتبديل بين العربية والإنجليزية.

## الميزات الموجودة

- تحليل عناوين الروابط المكتوبة أو الملصوقة من غير فتحها أو الاتصال بها.
- شرح مؤشرات مثل الرابط المختصر، عنوان IP، نطاقات فرعية كثيرة، حروف نطاق دولية، بيانات قبل اسم المضيف، وروابط غير مشفرة.
- رصد صياغات الرسائل التي تضغط على المستخدم أو تطلب بيانات حساسة أو تدعي وجود جائزة أو رسوم مفاجئة.
- تنزيل ملف بلاغ JSON يتضمن النطاقات والأسباب والوقت ومؤشر الاشتباه. لا يتضمن نص الرسالة، ولا يُرسل لأي جهة تلقائيًا.
- واجهة عربية وإنجليزية.

## الأدوات

- **Visual Studio Code** لتعديل الملفات.
- **HTML وCSS وJavaScript** لبناء وتشغيل الواجهة في المتصفح.
- **Git وGitHub** لحفظ نسخ المشروع ومشاركة الكود.
- للمرحلة التالية، يمكن إضافة **Python مع FastAPI** و**SQLite** لخادم وقاعدة بيانات. إرسال البلاغات أو التحقق من سمعة النطاقات يحتاج ربطًا بخدمة مناسبة وسياسة خصوصية واضحة.

## حدود النسخة الحالية

الفحص يعتمد على قواعد محلية بسيطة، وليس نموذج ذكاء اصطناعي أو قاعدة سمعة مباشرة. يفحص صيغة العنوان وبعض أنماطه فقط؛ لا يتصل بالموقع ولا يتحقق من محتواه أو سمعته الحالية. النتيجة مؤشر أولي وليست حكمًا بأن الرسالة آمنة أو احتيالية. زر البلاغ ينزّل ملفًا على جهازك ولا يرسل بلاغًا للشرطة أو شركة أو قاعدة بيانات مشتركة.
